# Trestle guide

Everything an agent needs to use and extend Trestle, one small read at a time. Read only what you
need; do not read Trestle's source or home.

- `trestle://guide/views`: which query view or fetch window to use
- `trestle://guide/plugins`: writing plugins and packs, an index of topics
- `trestle://guide/api`: the public plugin names, one line each
- `trestle://guide/examples/{name}`: a complete plugin ({examples})
